## 💡 Why This Project?

Most "AI short video generators" fail because:
1. **Generic Talking-head Scripts**: Dull lectures in the first 3 seconds lose viewers immediately.
2. **Slideshow Disease**: Abstract numbers turn into boring PPT charts instead of cinematic scenes.
3. **Audio-visual Desync**: Subtitles lag behind narration, ruining production value.
4. **Flat Narratives**: Zero stakes, no pressure ladder, and absent emotional payoff.

**AI-ShortVideo-Story-Engine** is reverse-engineered from viral short-form storytelling formulas (business thrillers, cautionary life traps, debt escapes, and counter-intuitive commercial models), packaged into an agent-native Skill.

> 📢 **A Note from the Author**:  
> This skill's strength lies in its **end-to-end automation**: with just one prompt, it generates complete narration lines, editing directives, storyboard prompts, and platform packaging. However, intricate long-form plot twists still benefit from community refinement. I have open-sourced the complete core knowledge base and skill definitions to spark innovation in the creator community. Contributions and PRs are warmly welcomed! If you find it helpful, please star ⭐️ this repository!

## 🔥 Key Features

- **🎯 Golden 3-Second Hooks**: Built-in hook bank tailored for Douyin/TikTok/YouTube Shorts retention.
- **🎭 Story-First Architecture**: Mandatory emotional contracts and pressure ladders before scene writing.
- **🎨 16:9 Comic Visuals (PPT-Free)**: All business data embedded organically into environmental story props (receipts, bills, phones).
- **⏱️ 5-8s Shot Cadence**: Measured pacing with explicit motion cues (static, smooth keyframe zoom, hard cuts).
- **🎙️ Sub-150ms Audio Sync Gate**: Precision rules preventing subtitle overhang and cumulative drift.
- **📱 Dual-Platform Publishing Bundles**: Tailored packages for Douyin (fast-paced) and Xiaohongshu/Instagram (save-oriented).

## 🚀 Quick Start

### Option 1: Claude Code / Codex / Antigravity
Clone and copy `skills/` to your agent skill directory:
```bash
git clone https://github.com/slad-dev/AI-ShortVideo-Story-Engine.git
cp -r AI-ShortVideo-Story-Engine/skills/* ~/.codex/skills/
```
Prompt:
> "Use `douyin-script` to create a 16:9 animated cautionary story about an entrepreneur escaping a franchise debt trap."

### Option 2: ChatGPT / Claude Web / DeepSeek
Copy `skills/douyin-script/SKILL.md` into your Custom Instructions or System Prompt, and give it any topic!
